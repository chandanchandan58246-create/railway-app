# 🚆 Railway Live Status

A railway information web application built by Chandan.

🌐 **Live Demo:** [Open Railway Live Status](https://railway-app-1bi4.onrender.com/)

## ✨ Features

- 🚆 Check train running status
- 🎫 Check PNR status
- 🔎 Find trains
- ⏱️ View train delay information
- 📱 Simple and user-friendly interface

## 🚀 How to Use

1. Visit the [Live Website](https://railway-app-1bi4.onrender.com/).
2. Choose the feature you want to use.
3. Enter the required train number, PNR number, or search details.
4. Submit your search and view the available results.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- RailRadar API

## 💻 Run Locally

```bash
git clone https://github.com/chandanchandan58246-create/railway-app.git
cd railway-app
npm install
```

Configure your `.env` file with your own API key:

```env
RAILRADAR_API_KEY=your_api_key_here
```

Start the backend server:

```bash
node proxy.js
```

Make sure the frontend, API endpoint, and server port match your project configuration.

## 🔐 Security

Never upload your API key or `.env` file to GitHub.
