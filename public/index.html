API connection settings
"Failed to fetch" fix: RailRadar's API doesn't send the browser CORS headers needed for a page to call it directly, so a pure frontend can't reach api.railradar.in on its own. This site now points at a tiny local proxy instead — download proxy.js (shared alongside this file), run node proxy.js in a terminal, and leave Base URL as-is. The proxy holds your API key server-side and forwards requests, so the key field above can stay blank. If you'd rather call RailRadar directly (e.g. once you confirm with their support that CORS is enabled for your plan), set Base URL back to https://api.railradar.in/v1 and put your key in the field above.
Built as a static frontend — no backend, no data stored anywhere.
